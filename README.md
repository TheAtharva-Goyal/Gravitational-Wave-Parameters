# Gravitational-Wave-Parameters
Finding the PDF of three parameters, alpha, beta and gamma using Metropolis-Hastings algorithm; given that we have experimental data regarding it.

Please go through the attached PDF for more details regarding the problem.

NOTE:
1. You will need to properly install Gnuplot for plotting the graphs
2. The gw_data.csv file must be in the same folder as the C file
3. Supposing everything goes fine and you get the graph of PDF of alpha (in a popup window), you will need to manually close each window to go to the next.
